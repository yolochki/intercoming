# ok, cool, how do i build this?
For building INTERCOMING you need to:<br>
- git clone https://github.com/yolochki/intercoming.git
afterwards you open Godot 4.2 and later and then open the project in it, then:
- click Project
- then click Export...
- add an export preset of your own
- click on the preset and click "Export"
<br>
Congratufabulations! You now have a funny intercom games!<br>
